# How to use LED MØNSTER

LED MØNSTER controls a compatible `BJ_LED_M` Bluetooth RGB LED strip from an Apple Silicon Mac.

## Install

1. Download **LED Monster.dmg** from the [latest release](https://github.com/DontxSleep/LED-Monster/releases/latest).
2. Open the DMG and drag **LED MØNSTER.app** to the Applications shortcut.
3. Eject the LED Monster disk image.
4. Open LED MØNSTER from Applications.
5. Allow Bluetooth access when macOS asks.

This personal build is ad-hoc signed and is not Apple-notarized. If macOS blocks the first launch, open **System Settings → Privacy & Security**, review the message for LED MØNSTER, and use **Open Anyway** only if you downloaded the release from this repository.

## Connect the LED strip

1. Connect power to the LED controller and keep the Mac close to it.
2. Close MohuanLED and any other phone or computer app that may already be connected.
3. Click the menu button in the top-left corner.
4. Click **Scan nearby**.
5. Find **BJ_LED_M** under **Your lights** and click **Connect**.
6. Wait until the connection reports that controls are ready.
7. Close Parameters to return to the full controller.

The app only enables light controls after it discovers the expected `EEA0` service and writable `EE01` characteristic.

## LED MØNSTER pads

The main screen behaves like a momentary lighting instrument:

- Hold a pad to switch on its colour.
- Release it to switch the strip off.
- Hold more than one input to layer performance gestures; releasing the latest input restores the previous held colour.
- The monster eye changes to the active colour and returns to blue when every pad is released.

| Computer key | Pad colour | MIDI note |
| --- | --- | --- |
| Q | Red | 60 |
| W | Green | 61 |
| E | Blue | 62 |
| R | Yellow | 63 |
| T | Cyan | 64 |
| Y | Magenta | 65 |
| A | Orange | 66 |
| S | Spring green | 67 |
| D | Violet | 68 |

## MIDI keyboard or DAW

1. Open Parameters.
2. Enable **MIDI keyboard**.
3. Connect a USB MIDI keyboard or route MIDI from music software to **LED MØNSTER Input**.
4. Send notes 60–68 on any MIDI channel.

Note-on activates a pad. Note-off, including note-on with zero velocity, releases it. Velocity does not change brightness.

To receive notes generated by clicking pads or pressing Q/W/E/R/T/Y/A/S/D, select **LED MØNSTER Pads** as the input in your music software.

## Mood mode

1. Open Parameters and choose **Mood mode** as the third Programme mode.
2. Select Relax, Sunset, Ocean, Forest, Focus, or Midnight.
3. Choose a transition:
   - **Drift** — 16-second colour movement.
   - **Glow** — 8-second colour movement.
   - **Flow** — 4-second colour movement.
4. Set brightness.
5. Click **Start mood**.

Brightness changes are sent while the mood is running. **Stop**, **Off**, opening Parameters, changing programme mode, disconnecting, or quitting stops the sequence safely.

## LED MØNSTER VFX

1. Choose **LED MØNSTER VFX** in Programme mode.
2. Select exactly four colours.
3. Choose Colour Flash 1, Quick, Slow, Fade, or Jump.
4. Set a tempo by clicking **Tap to BPM** or tapping the Spacebar repeatedly.
5. Set brightness and click **Start VFX**.

Effects use the verified RGB colour command and are sequenced locally by the Mac.

## Colour studio

Use Colour studio for a steady light:

- Pick a colour from the colour wheel.
- Adjust brightness.
- Open Fine tune for RGB sliders or a six-digit hex value.
- Select **Apply to strip**.
- Name and save frequently used colour scenes on the Mac.

## Turn everything off

Use **Off** in the top-right corner as an immediate stop. It stops active Mood/VFX scheduling and sends the controller's verified power-off command.

## Troubleshooting

### The strip does not appear

- Confirm the controller has power.
- Move the Mac closer.
- Close MohuanLED on your phone.
- Stop scanning, wait a moment, and scan again.
- Use **Show other devices** only for diagnosis; controls still require `BJ_LED_M`.

### It connects but controls stay disabled

The device must expose service `EEA0` and a writable `EE01` characteristic. Open **Connection details** to inspect what the controller advertised.

### The app cannot reconnect

Disconnect the controller, power-cycle the LED strip, close other controller apps, and scan again.

### Export a diagnostic report

Choose **Controller → Export report…** from the macOS menu bar. The JSON report contains nearby device identifiers and raw Bluetooth details, so review it before posting it publicly.
